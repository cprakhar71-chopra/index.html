Terminal Navigation Practice Sheet

Objective

To learn basic terminal commands for navigating folders and managing files.

1. Check the Current Directory

Command:
"pwd"

Purpose: Displays the current working directory in Git Bash, Linux, and macOS terminals.

2. List Files and Folders

Command:
"ls"

Purpose: Displays the files and folders in the current directory.

3. Change Directory

Command:
"cd folder-name"

Purpose: Moves into the specified folder.

4. Move to the Parent Directory

Command:
"cd .."

Purpose: Moves one level up from the current directory.

5. Create a New Folder

Command:
"mkdir Practice"

Purpose: Creates a folder named Practice.

6. Create a File

Command:
"touch index.html"

Purpose: Creates an empty file in Git Bash and other compatible terminals.

7. Display the Current Directory Contents

Command:
"ls"

Purpose: Checks whether the new folder or file exists.

8. Return to the Home Directory

Command:
"cd ~"

Purpose: Moves to the user's home directory in compatible terminals.

Conclusion

I practised basic terminal commands for checking directories, listing files, navigating folders, and creating files. These commands help me manage project files and work efficiently with Git and GitHub.
